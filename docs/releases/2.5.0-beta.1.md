# Esports Stream Control 2.5.0-beta.1

This beta adds six game-specific companion scoreboards with map/game history,
confirmed results, side assignments, corrections, undo and recovery after restart.
One Windows x64 installer contains Widener Esports, League of the East and
Messiah Esports.

| Profile | Updated companion scoreboards |
| --- | --- |
| Widener | VALORANT, Overwatch, Marvel Rivals, League of Legends, Rainbow Six Siege, Call of Duty |
| League of the East | VALORANT, Overwatch, Marvel Rivals |
| Messiah | VALORANT, Overwatch, Marvel Rivals, League of Legends, Call of Duty |

Rocket League's live scoreboard and Smash's crew-battle scoreboard remain available.

## Install and try it

Download **Esports-Stream-Control-Setup-2.5.0-beta.1.exe** from this release.
Close the app and run the installer. This updates an existing installation;
it uses the same profile data folders. Existing settings and saved matches are
kept. Select your profile, choose a supported game under Match, then open Live
for the new series controls. Build scenes to refresh OBS browser sources.

Before playing, confirm the series format, map schedule, native HUD sides and
your organizer's rules. Start each map/game explicitly. Finish map opens result
review; Confirm result awards exactly one win. Draws, forfeits, administrative
results, voids, remakes and corrections are explicit actions. Undo restores the
record and its displayed series score together.

## Game-specific controls

- **VALORANT:** maps won, map picks, independent HUD and attack/defense sides,
  pause labels and optional final rounds.
- **Overwatch:** editable mode rotation, draws, extra tiebreaker maps, per-map
  hero bans and mode-specific final results.
- **Marvel Rivals:** Domination/Convoy/Convergence, separate bans and protected
  locks, objective summaries and explicit mode selection for extra maps.
- **League of Legends:** games won, blue/red mapping for every game, optional
  draft/trade confirmation, team/global Fearless exclusions and admin-approved
  draft carry on remake.
- **Rainbow Six Siege:** configurable regulation and capped/unlimited overtime,
  role/phase history, operator bans and rehost continuations with retained scores.
- **Call of Duty:** required title/season, editable mode schedules including BO7,
  per-mode map pools, point/round/custom result units and admin continuations.

The compact board defaults to the bottom left above the app ticker. Adjust its
corner, insets and scale for the observer HUD. Show map history during breaks;
starting play collapses it. Saved matches retain competition settings and the
schedule without importing played results or drafts into a new match.

This beta also includes the branch's Messiah presentation/player-camera work,
Rocket League player-camera automation, league-feed updates and the Stats scene
entrance fix.

## What testers should check

Use the native spectator HUD for live rounds, objectives, clocks and player data.
These six boards are manual companion graphics. Example rotations and title
presets are labeled research examples; confirm the actual NECC, LotE or custom
event rulebook and record its version in Competition rules and source.

Please check your actual observer HUD for overlap at the streaming resolution,
school identity through native side changes, game capture/audio, pauses, remakes,
rehosts, a decisive map, restart recovery and broadcast delay alignment. Real
game/OBS capture and venue camera signals still require tester verification.

This is a GitHub prerelease. Stable installations remain on the stable release;
testers install this beta directly. Beta installations can receive subsequent
beta updates through the existing updater.
