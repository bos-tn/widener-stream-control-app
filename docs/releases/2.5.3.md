# Esports Stream Control 2.5.3

- Standings scene: a table without a playoff rule no longer shows "Playoff cutoff unverified" in the bottom-left corner; the legend is left out. Tables with a rule (NECC Rocket League) still show the playoff legend. The League page still reports the missing rule to the operator. Affects every profile.
- Match page: League of the East now opens on the Match step, with the LeagueOS match link and **Import** first and **Manual setup** after it, the same five steps as Widener and Messiah. The Teams step no longer has a Match link tab; its sources are LotE schools and Manual. After the update the Match page opens on step 1 once in every profile.

Messiah remains locked in this stable release. Based on v2.5.2; unfinished scoreboard overhaul changes are excluded.
