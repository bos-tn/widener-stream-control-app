# Esports Stream Control 2.5.1

- Adds Standings to the default scene build. Imported matches select their league, division and conference group, with every team, records and the current league week.
- Refreshes standings automatically, keeps a separate offline cache for each group, and pages larger tables.
- Marks the top four NECC Rocket League positions per current conference group, with a cutoff divider and unresolved-tie markers. Uses the supplied NECC Rocket League Rulebook, Fall 2025–Spring 2026 edition, section 4.b.iii, page 9, at the operator's request. Positions are provisional; LotE qualification remains unmarked.

Messiah remains locked in this stable release. Based on v2.5.0; unfinished scoreboard overhaul changes are excluded.
