# Esports Stream Control 2.5.4

- Rocket League scoreboard: the board sits 8 px from the top of the screen instead of 16 px, and the team boost rows on the screen edges sit 8 px from the top instead of touching it. The goal banner moves up with the board. Other scoreboards keep their 16 px gap.
- Rocket League scoreboard: the kickoff countdown (3, 2, 1, GO) is drawn in the middle of the screen while the app has the game's HUD hidden. The game's own countdown is part of the HUD, so it disappeared with **Hide game HUD while spectating**. With that setting off, the game draws its own countdown and the board draws none.
- Widener: new **Caster Cam** scene. The camera is connected like Crowd Cam and Comp Room (a network address or a device, Broadcast > Cameras). The caster is cut out of the picture and shown over the scene's background (W Shine by default, picked under the scene), with the camera scene's graphics on top. Scenes > Build adds OBS's background removal to the camera: **NVIDIA Background Removal** when NVIDIA's Video Effects SDK is installed (RTX cards), else the **Background Removal** plugin if installed. With neither, the build result says how to add one, and the whole camera picture shows. On an existing install the Caster Cam is ticked once; build scenes after the update.

Messiah remains locked in this stable release. Based on v2.5.3; unfinished scoreboard overhaul changes are excluded.
