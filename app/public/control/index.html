How does scoring work?

Click Won on a team when they take a game, map or set. For Smash crew battles, turn on the stock counter: each team shares a pool of stocks, players go in the order listed under Prep, Teams, and the first player with stocks left is shown as on stage.

  1. Click Lost a stock each time a player loses a stock. Undo reverses a misclick.
  2. When a team runs out, click Won on the winning team. It adds a point and refills both teams' stocks.
  3. The keys shown on the buttons work too, while this card is on screen and you are not typing.

Rocket League reads the game itself: goals, clock, boost and stats come from the game, and each finished game adds a win to its team automatically. Blue is the left side: if team A is playing orange, click Swap sides. Use the + and − buttons to correct a series score.

What does this do?

The app connects to the WebSocket server built into OBS 28 and newer and builds one scene per overlay. After that, every Push Live switches OBS to the matching scene with OBS's own transition, and background music plays between games. Switching scenes by hand in OBS moves the red Live marker to match.

Once connected, the app reconnects on its own if OBS is closed or restarted.

  1. In OBS, open Tools then WebSocket Server Settings.
  2. Enable the server and copy the password.
  3. Fill in the password below and click Connect.
  4. Click Build or update scenes in OBS.

How does the music play?

The included track downloads from the team Google Drive (36 MB) the first time it is needed, like the game videos. Or pick any audio file on this PC.

OBS plays it, through one media source called {{prefix}}: Music that Build or update scenes adds to every {{prefix}} scene, so it carries on through scene changes instead of starting over. The app fades it up and down, so the app must be switching your OBS scenes (above) for music to play.

Set up the stream app

This takes about two minutes: connect OBS, then download the game videos. You can change anything later in Settings.

How should OBS show the overlays?

Connect to OBS

  1. In OBS, open Tools, then WebSocket Server Settings.
  2. Tick Enable WebSocket server.
  3. Click Show Connect Info and copy the password.

Add the overlay to OBS

  1. In OBS, click + under Sources and choose Browser.
  2. Paste this address as the URL.
  3. Set the width to 1920 and the height to 1080, then click OK.

Use the same source in every scene that needs the overlay. The address never changes.

Download the game videos?

Starting Soon, Post-Match and Be Right Back play a highlight video for the selected game. Downloading them now keeps a download from starting mid-stream.
