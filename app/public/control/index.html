How do I set this up?

OBS can host this control panel as a dock, right beside your scenes. It is the same panel, just embedded in the OBS window.

  1. In OBS, open Docks then Custom Browser Docks…
  2. Give it a name, such as Widener Control.
  3. Paste the URL below, then click Apply.

OBS scene-sync Optional

What does scene-sync do?

It connects to the WebSocket server built into OBS 28 and newer, then builds one scene per overlay type. After that, every Push Live switches OBS to the matching scene using OBS's own transition, such as the Widener stinger.

The overlay content inside each scene still updates live, exactly as it does today. Leave this disconnected to keep the classic single-source setup. Nothing here is required.

  1. In OBS, open Tools then WebSocket Server Settings.
  2. Enable the server and copy the password.
  3. Fill in the fields below and click Connect.
  4. Click Build / update scenes, then turn scene-sync on.
