    How do I connect?
    1. In OBS, open Tools then WebSocket Server Settings.
    2. Tick Enable WebSocket server, click Show Connect Info and copy the password.
    3. Paste it below and click Connect. The app connects again by itself from then on.

    Set up {{appName}}

    The app runs the stream through OBS: it builds a scene for every overlay, and you switch between them in OBS (or let the app do it, like cutting to the stats after a Rocket League game). Here it connects to OBS, builds the scenes and sets up the {{short}} stinger transition. About five minutes.

    You need OBS 30 or newer, open on this PC.

    1. Connect to OBS

    1. In OBS, open Tools, then WebSocket Server Settings.
    2. Tick Enable WebSocket server.
    3. Click Show Connect Info and copy the password.

    2. Build the scenes

    The app makes a scene collection called {{short}} Stream with one scene per overlay. Your other scene collections are not touched.

    3. Add the {{short}} stinger

    4. Download the game videos?

    Starting Soon and Post-Match play a highlight video for the selected game. Downloading them now keeps a download from starting mid-stream.

    You're set

    Next, set up a match on the Match page: the game, the teams, the start time. Then run the show from OBS, and keep score and fix names on the Live page.
